# Bhavik Patel — Portfolio

Personal developer portfolio built with **React 18 + Vite**.

## ✨ Features
- Animated hero with typewriter effect
- Scroll-reveal animations on all sections
- Glassmorphism project cards
- Skill progress bars
- Dark mode
- Fully responsive

## 🛠 Tech Stack
- React 18
- Vite
- CSS Animations & Custom Properties

## 📦 Setup
```bash
npm install
npm run dev
```

## 🚀 Deploy
```bash
npm run build
# deploy dist/ to Vercel
```
